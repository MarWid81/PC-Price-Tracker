# PC Price Tracker

PC Price Tracker to prywatny projekt aplikacji służącej do porównywania i monitorowania cen podzespołów komputerowych.

## Planowane funkcje
- Wyszukiwanie procesorów, kart graficznych, pamięci RAM, dysków SSD i innych komponentów.
- Porównywanie ofert nowych i używanych produktów.
- Monitorowanie zmian cen i prezentowanie historii cen.
- Automatyczne sprawdzanie cen co 6 godzin.
- Dostęp do interfejsu z komputera i telefonu.

## Integracja z Allegro
Aplikacja wykorzystuje API Allegro do wyszukiwania produktów w katalogu Allegro.

Projekt jest rozwijany na własny użytek i nie jest powiązany z firmą Allegro.
